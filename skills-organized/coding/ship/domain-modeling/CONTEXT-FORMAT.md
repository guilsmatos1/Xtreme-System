# CONTEXT.md Format

```md
# {Context Name}

{One or two sentences: what this context is.}

## Language

**Term**:
{One or two sentences: what it IS.}
_Avoid_: Synonym1, Synonym2
```

## Rules

- Be opinionated: pick one word; list rejects under `_Avoid_`.
- Definitions tight — what it IS, not what it does.
- Only project-specific domain terms (not general programming concepts).
- No implementation details, file paths, or API shapes in `CONTEXT.md`.
