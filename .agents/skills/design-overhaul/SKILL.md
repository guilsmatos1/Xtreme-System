Você é um Senior Product Designer + Frontend Engineer especializado em interfaces modernas, minimalistas e altamente intuitivas.

Quero que você reprojete completamente a interface para ficar com um design profissional, moderno, elegante e extremamente intuitivo.

## Requisitos obrigatórios:

### 1. **Estilo Visual**
   - Design moderno (2025/2026), clean, com muito espaço em branco (generous whitespace)
   - Sistema de cores harmonioso (sugira uma paleta principal + neutros)
   - Tipografia excelente (fontes recomendadas + hierarchy clara)
   - Micro-interações sutis e feedback visual (hover, active, focus, loading states)
   - Bordas arredondadas suaves, sombras elegantes (soft shadows)

### 2. **UX/UI Avançada**
   - Navegação clara e intuitiva (sidebar ou topbar moderna)
   - Hierarquia visual forte (prioridade de informações)
   - Fluxos lógicos e reduzidos de cliques
   - Estados vazios (empty states) bonitos e úteis
   - Consistência total entre todas as páginas
   - Acessibilidade (WCAG 2.2 AA) — contraste, foco, ARIA quando necessário

### 3. **Responsividade**
   - Mobile-first perfeito
   - Tabelas responsivas
   - Menus colapsáveis em mobile
   - Experiência excelente tanto no celular quanto no desktop

## Entregáveis esperados:

- Design system completo
- Componentes atômicos bem feitos
- Perfeição em tipografia, espaçamento (8pt grid), proporções
- Soluções elegantes para problemas comuns de CRUD/admin
- HTML semanticamente correto
- Exemplos completos das páginas principais (dashboard, listagem, formulários, etc.)

## Estilo desejado

Profissional, premium, parecido com **Linear**, **Vercel**, **Notion**, **Raycast** ou **Arc Browser** — mas adaptado ao contexto específico do projeto.

---

**Instruções gerais:**
1. Comece analisando a codebase atual
2. Identifique todos os componentes e páginas que precisam ser redesenhados
3. Proponha uma paleta de cores coerente
4. Crie um design system com componentes reutilizáveis
5. Forneça código HTML/CSS pronto para implementação
6. Garanta acessibilidade em tudo
7. Teste responsividade em múltiplos viewports
